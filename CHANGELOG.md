# Changelog

All notable changes to this project will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2025-04-28

### Added
- Initial release of MCP Blockly Studio
- Visual block-based programming environment for MCP applications
- Monaco editor integration for viewing generated JavaScript code
- Four tutorial projects: Echo Server, Weather Client, Task Assistant, and Image Generator
- Custom blocks for MCP server and client components
- Support for different transport types (stdio, HTTP streaming)
- Authentication, notification, and prompt implementation blocks
- Code generation for JavaScript
- Download functionality for generated code

### Changed
- Updated toolbox with MCP-specific categories
- Improved block designs for better usability

### Fixed
- Initial stability issues with Monaco editor integration
- Block connectivity issues in complex workflows

## [0.1.0] - 2025-04-15

### Added
- Basic project structure
- Initial implementation of Blockly workspace
- Core MCP blocks implementation
- Basic code generation functionality

### Changed
- Updated development environment with Webpack configuration
- Enhanced block definitions
